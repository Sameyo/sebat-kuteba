# Sebat Kuteba: group savings tracker (Android + iOS)

Track a shared monthly savings pool for a group. Set the monthly amount once, add the people, and tap a name on the home screen when they pay.

Built with Flutter, so one codebase runs on Android and iOS.

## Using the app

- **Home screen** shows the current month with everyone in the group.
- **Tap a name** to mark them paid for the month shown. Tap again to undo.
- **‹ ›** switches between months, back to the month collection started.
- **Pencil icon** on the top card sets the monthly amount and the month collection started (default: Apr 2026).
- **Calendar icon** on a name (or long-press the name) opens that person's months. Tick individual months, or pick a "from – to" range and mark it paid or unpaid in one go. Removing the person is at the bottom.
- **Add person** adds a member.
- Each name shows how many months they still owe.

Data is stored privately on the device (one JSON blob via `shared_preferences`). Nothing is sent anywhere.

## First-time setup

This repo contains the app code (`lib/`, `pubspec.yaml`). The Android and iOS platform folders are generated by Flutter on your machine:

```
flutter create --platforms=android,ios --project-name sebat_kuteba --org com.savingstracker .
flutter pub get
flutter run
```

If `flutter create` overwrites `lib/main.dart`, restore it with `git checkout lib/main.dart`.

Requirements: [Flutter SDK](https://docs.flutter.dev/get-started/install) 3.27 or newer. Android builds need Android Studio / the Android SDK. iOS builds need a Mac with Xcode (an Apple developer account is needed to install on a physical iPhone or use TestFlight).

Build an installable file:

```
flutter build apk          # Android
flutter build ipa          # iOS (on a Mac)
```

## Code layout

```
lib/
  main.dart               Entry point
  home_page.dart          The home screen and its dialogs
  ledger_controller.dart  Add/remove members, toggle paid, save settings
  ledger_store.dart       On-device storage
  models.dart             Member / Payment / LedgerState, YearMonth
  theme.dart              Colours
```
